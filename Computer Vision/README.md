## Course Description

This course covers the theory and application of computer vision using Python and deep learning frameworks. Topics span image classification, object detection, convolutional neural networks (CNNs), transfer learning, and real-time image processing with OpenCV.

---

## Topics Covered

- Image loading, transformation, and preprocessing with OpenCV
- Feature extraction and traditional CV methods
- Convolutional Neural Networks (CNNs) from scratch
- Transfer learning with pre-trained models (VGG, ResNet, MobileNet)
- Object detection (YOLO, SSD)
- Image segmentation
- Model evaluation: accuracy, precision, recall, mAP
