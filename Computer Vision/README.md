## 🔑 Key Themes Across Labs

### **1. Representation Learning**
- Lab 3: Raw pixels vs. engineered features (HOG, LBP)
- Lab 4: Learned CNN features beat hand-crafted
- Lab 8: Multimodal embeddings (vision + text)
- **Insight:** Better representations → better downstream performance

### **2. Generalization vs. Overfitting**
- Lab 3: 99% training accuracy ≠ good model
- Lab 5: Recognize data bias (blueberry muffins)
- Lab 8: Hallucinations are confident falsehoods
- **Insight:** Validation gap is the real signal

### **3. Real-World Challenges**
- Lab 5: Model bias from training data
- Lab 8: Deployment trade-offs (API vs. self-hosted)
- Lab 11: Occlusion and ID switching in video
- **Insight:** Lab metrics ≠ production performance

### **4. Ethical Considerations**
- Lab 5: Bias and fairness in CNNs
- Lab 8: Hallucinations in high-stakes applications
- Lab 11: Surveillance and privacy concerns
- **Insight:** Technical capability requires ethical responsibility

### **5. System Architecture**
- Lab 9: Perception → Reasoning → Action loop
- Lab 10: Tools + Workflow + Memory framework
- Lab 11: Temporal tracking at scale
- **Insight:** Good abstractions enable powerful systems
