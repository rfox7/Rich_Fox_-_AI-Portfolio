## 🚀 Key Insights

### **From Computer Vision:**
1. **Representation learning matters:** Hand-crafted features → CNN features → multimodal embeddings
2. **Fairness in vision:** Models inherit biases from data; hallucinations are systematic
3. **Agents are systems:** Perception + reasoning + action = autonomous behavior
4. **Temporal understanding:** Tracking objects over time requires handling identity and occlusion

### **From Machine Learning:**
1. **Data is everything:** 80% of effort goes to data, not models
2. **Generalization > Accuracy:** Train/test gap reveals overfitting
3. **Ensemble wisdom:** Combining diverse models beats any single approach
4. **Ethics is mandatory:** Fairness, bias detection, and transparency are non-negotiable

### **Across Both Courses:**
1. **Workflow matters:** Both vision and ML have universal workflows
2. **Evaluation is critical:** Going beyond accuracy to appropriate metrics
3. **Real-world challenges:** Lab performance ≠ production performance
4. **Ethical AI is essential:** Every model must be audited for bias and fairness
