## How to Run the Notebooks

### Prerequisites

- Python 3.7+
- Jupyter Notebook or JupyterLab

### Setup

```bash
# Clone this repository
git clone https://github.com/rfox7/Rich_Fox_-_AI-Portfolio.git
cd Rich_Fox_-_AI-Portfolio

# Install common dependencies
pip install numpy pandas matplotlib scikit-learn tensorflow keras torch opencv-python jupyterlab
```

### Launch

```bash
jupyter notebook
```

Then navigate to any `.ipynb` file inside `Machine Learning/` or `Computer Vision/`.
